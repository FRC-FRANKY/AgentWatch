# Data Retention Policy — AgentWatch
**Version:** 1.0 | **Effective Date:** [Date]

## 1. Purpose

This policy defines how long different categories of data generated by AgentWatch are retained, in compliance with the Philippine Data Privacy Act of 2012 (RA 10173) — particularly the principle of **proportionality and limited retention**.

## 2. Data Categories and Retention Periods

| Data Category | Default Retention | Configurable | Notes |
|---------------|------------------|--------------|-------|
| **Audit logs** | 365 days | Yes (`AUDIT_LOG_RETENTION_DAYS`) | Immutable. Cannot be modified or deleted. |
| **Security events** | 365 days | Yes (`SECURITY_EVENT_RETENTION_DAYS`) | |
| **Monitoring session metadata** | 90 days | Yes (`MONITORING_SESSION_RETENTION_DAYS`) | Metadata only — no screen content |
| **Refresh tokens** | 30 days | Yes | Revoked tokens purged after 30 days |
| **Screen content** | **0 days — not stored** | No | By design. Screen viewing is live only. |
| **Keystrokes** | **Never collected** | No | Prohibited feature |
| **Webcam/mic data** | **Never collected** | No | Prohibited feature |
| **User accounts** | Indefinite while employed | N/A | Deactivated on termination |

## 3. Automatic Purging

The system includes scheduled tasks to purge expired data:

```sql
-- Purge old monitoring sessions (metadata only)
DELETE FROM monitoring_sessions
WHERE ended_at < NOW() - (CURRENT_SETTING('app.session_retention_days') || ' days')::INTERVAL
  AND status NOT IN ('ACTIVE', 'PENDING');

-- Purge old refresh tokens
DELETE FROM refresh_tokens
WHERE expires_at < NOW() - INTERVAL '30 days';
```

## 4. Audit Log Integrity

Audit logs are **never purged automatically**. Purging must be:
1. Approved by the Data Privacy Officer
2. Documented in a separate administrative audit record
3. Done via a controlled administrative procedure, not application code

## 5. Compliance

Retention periods are set to comply with:
- RA 10173 proportionality principle
- NPC Circular 16-01
- Company records management policy

## 6. Review

This policy is reviewed annually by the DPO.
