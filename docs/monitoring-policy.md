# Monitoring Policy

AgentWatch supports only transparent, consent-aware monitoring for company-owned workstations used for authorized business operations.

## Allowed use cases

- Operational supervision for approved departments
- Security event investigation on managed devices
- Remote troubleshooting with explicit authorization

## Prohibited use

- Monitoring personal devices
- Hidden or covert access
- Screen recording or raw keystroke capture
- Activating webcams or microphones without explicit approval
- Access without a valid session reason and audit record

## Session controls

- Managers must provide a purpose when requesting monitoring.
- Each session is logged with IP, user, time, and device metadata.
- Sessions are limited to authorized agent-device pairs.
- Session end events are required for audit completeness.
